# DrewMauldin GitHub defaults

This public repository provides default issue and pull-request templates for repositories owned by DrewMauldin.

GitHub applies these files only when a repository does not provide its own equivalent. A repository with any file in its own `.github/ISSUE_TEMPLATE/` directory overrides this repository's complete issue-template directory.

The templates are intentionally generic and public. Do not include credentials, customer data, private host details, unpublished product information or other sensitive values in issues or pull requests.

Repository-specific contributing, security and release requirements remain authoritative.
